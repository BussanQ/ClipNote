# ClipNote · 原生文本剪贴板

ClipNote 是 Windows 系统托盘和 macOS 12+ 菜单栏上的文本剪贴板工具，使用 Go 和 [mygo 原生 UI](https://mygo.run/docs/ui) 绘制窗口、列表和搜索框。

## 使用

Windows 用户解压与系统架构相符的便携包，双击 `ClipNote.exe`。macOS 用户打开 `ClipNote.app`，在「系统设置 → 隐私与安全性 → 辅助功能」允许 ClipNote 直接粘贴，也可从面板点击「开启权限」。

| 操作 | Windows | macOS |
| --- | --- | --- |
| 打开或收起历史面板 | Ctrl+J | ⌘J |
| 面板中粘贴第 1–5 条搜索结果 | Ctrl+1 至 Ctrl+5 | ⌘1 至 ⌘5 |
| 面板隐藏时粘贴最近五条中的一条 | Ctrl+1 至 Ctrl+5 | ⌘1 至 ⌘5 |

在目标应用中复制文本，按快捷键呼出面板，输入关键词搜索。用 ↑ / ↓ 选择后按回车，或双击条目，均可粘贴到呼出面板前的输入位置。隐藏面板时，数字 1 对应最新记录。也可以从托盘或菜单栏图标打开面板。ClipNote 运行期间会全局占用成功注册的组合键。

每条记录右侧都有删除按钮。设置中可配置 **1–365 天**（默认 **7 天**），缩短天数会立即清理已过期记录。

## 历史与隐私

只记录启动后新复制的文本，跳过文件、纯图片和带有机密标记的内容。Windows 还会跳过明确禁止进入系统剪贴板历史的文本。未标记的密码仍可能进入历史。历史以明文保存在本机。

| 平台 | 历史文件 | 访问权限 |
| --- | --- | --- |
| Windows | `%APPDATA%\ClipNote\history.json` | 继承用户配置目录的 Windows 访问控制权限 |
| macOS | `~/Library/Application Support/ClipNote/history.json` | 文件权限为 `0600` |

来源名称取自检测到复制时的前台应用，快速切换窗口或后台复制时可能有偏差。只保存应用名称和标识（Windows 为程序路径），图标从本机读取，无法识别时显示通用图标。

单条最大 1 MiB，最多保存 3,000 条或 16 MiB 文本。重复记录合并并移到最前。直接粘贴会把选中的文本留在系统剪贴板，并跳过本次回写的历史采集。目标应用需要支持 Ctrl+V 或 ⌘V 并保留编辑位置。Windows 普通权限程序向管理员窗口发送粘贴按键可能受限，此时可手动粘贴。

## 构建

需要 Go 1.27.3 或更新版本。在源码目录运行以下命令。

**Windows（PowerShell）**

```powershell
.\build-windows.ps1
```

默认构建 x64 和 ARM64 两套便携包，分别为 `dist/ClipNote-windows-amd64.zip` 和 `dist/ClipNote-windows-arm64.zip`。单独构建一个架构可使用 `-Arch amd64` 或 `-Arch arm64`。脚本输出每个 ZIP 的 SHA-256，独立可执行文件在对应的 `dist/windows-<架构>/` 目录下。

**macOS**

```sh
./build-macos.sh
open dist/ClipNote.app
```

脚本构建当前 Mac 架构并做本机签名。重建后如直接粘贴权限未沿用，可在系统设置中重新授予当前构建。

## 验收

运行 `go test ./...` 检查快捷键、搜索、双击、删除和历史存储。桌面粘贴可用记事本或 TextEdit 验收：

1. 启动 ClipNote，在编辑器中依次复制两段易于区分的测试文本。
2. 输入「左右」，把光标放在两字之间。呼出面板并按 Ctrl+2（macOS 为 ⌘2），确认第一段文本插在光标处。
3. 重置编辑内容，在面板中双击另一条记录，再检查插入位置。
4. 收起面板，在编辑器中按 Ctrl+1（macOS 为 ⌘1），确认粘贴最近的记录，历史顺序保持不变。
