# ClipNote · 原生文本剪贴板

macOS 12+ 的菜单栏工具。Go + [mygo 原生 UI](https://mygo.run/docs/ui)，没有 WebView、HTML 或 JavaScript 前端。窗口、列表、搜索框和深浅色样式均由 mygo 的原生绘制实现。

## 使用

1. 按下文构建后，打开 ClipNote.app。直接粘贴需要在「系统设置 → 隐私与安全性 → 辅助功能」允许 ClipNote。可从面板点击「开启权限」。无需更改 Gatekeeper 全局设置。
2. 在任意应用复制纯文本。按 **⌘J** 呼出或收起。也可以通过菜单栏图标打开。
3. 输入关键词搜索，也可用 ↑ / ↓ 选择条目；**⌘1–5** 粘贴对应的搜索结果。面板隐藏时，在目标应用的输入位置直接按 **⌘1–5** 即可粘贴最近五条历史中的对应条目（⌘1 为最新）。ClipNote 运行期间会全局占用成功注册的组合键。双击一行或选择后按回车也会使用同一粘贴流程。应用收起面板、确认原应用仍在前台后，只向该进程发送系统粘贴按键，使用原应用保留的光标或选区；不会点击坐标。
4. 每条记录右侧都有独立的删除按钮。设置中可配置 **1–365 天**（默认 **7 天**），缩短天数会立即清理已过期记录。

只记录启动后新复制的文本，不记录文件、图片或明确标记为机密的内容。未标记的密码仍可能进入历史。记录仅保存在本机，文件路径为 `~/Library/Application Support/ClipNote/history.json`，文件权限为 0600；不是加密保险箱。新条目可显示检测到复制时的前台应用名称和图标。macOS 剪贴板不提供可靠的写入者信息，切换应用或后台写入时可能不是实际来源；旧记录或未识别条目仍可正常使用，显示通用图标。仅把应用名称和标识存入本地历史，图标在本机读取，不访问网页或下载网站图标。单条最大 1 MiB，最多 3,000 条或 16 MiB 文本。重复记录合并并移到最前。直接粘贴会把该文本留在系统剪贴板，但不会重新写入历史。目标必须支持 ⌘V，并保持原有编辑位置；锁屏、受保护字段或不接受合成键的应用不保证支持。

## 在 Mac 本地构建

先准备 Go 1.27.3 或更新版本。解压源码后，在该目录运行：

```sh
./build-macos.sh
open dist/ClipNote.app
```

脚本构建当前 Mac 架构并做本机签名，不安装后台启动项也不更改系统安全设置。重建后如直接粘贴权限未沿用，可在系统设置中重新授予当前构建。

## 验收

本次改版仅交付源码，未运行构建或测试。源码保留了快捷键、双击、搜索、删除和历史存储的测试用例。

macOS 原位粘贴必须从真实桌面验收：用 TextEdit 复制两段测试文本；在新文档键入 `左｜右` 并把光标移到「｜」旁边。按 ⌘J 后按 ⌘2，核对插入在同一光标处。重置文档并再次呼出，双击另一条，核对同样原位插入。可用 Safari 或 VS Code 的输入区再重复一遍。构建及无窗口测试不等同于这项端到端验收。
